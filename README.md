## Car Racing Game – Python

A simple and fun Car Racing Game built using Python.
where the player controls a car and avoids obstacles while trying to achieve the highest score.
This project showcases basic game development concepts, collision detection, and event handling in Python.

## Features

 Player-controlled racing car

 Randomly generated obstacles

Live score system

Increasing difficulty as the game progresses

Smooth keyboard controls

Uses sprites / assets for visuals (if included)

## Technologies Used

Python

Pygame (or mention the library you used)

Basic game loops

Collision detection

## ▶️ How to Run

Install Python (if not installed)

Install required library:
pip install pygame

Run the game:
python car_racing_game.py
